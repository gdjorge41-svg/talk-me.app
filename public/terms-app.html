1. Talk-me 平台的使用

Talk-me是一款离线通讯工具，通过经过处理的WebRTC协议和网络遥测进行语音传输。它严格设计用于声学表演、现场制作和隔离部署（“零云”）中的专业用途。其在不安全、WAN 或开放网络下的操作由网络管理员全权负责。

2. 智能语音处理（本地AI）

人工智能引擎（Vosk）在中心节点的CPU上执行100%本地词典识别数学模型。用户同意他们的声音被麦克风（“AudioWorklet Node”）捕获，以数学方式转换为低频 PCM 块（16kHz），并传输到主服务器进行即时处理。所有语义处理都发生在内联网内。

3. 隐私和缺乏外部数据库

隐私是该架构设计的基石。 Talk-me 缺乏与第三方云、商业分析生物识别系统或持久云数据库的连接。音频数据包 (ArrayBuffer Blob PCM) 或命令 (OSC) 一旦收到就会过期。语义词典保存在本地。

4. 浏览器 API 的使用（“浏览器注入”）

通过接受此服务，您允许 Talk-me 调用操作系统通知（“通知 API”）、操纵扬声器设备（“sinkId”）或使用手电筒（“MediaTrackConstraints”）和触觉振动电机（“Navigator.Vibrate”）激活本地物理执行器，以保证发出红色警报。
